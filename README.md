# Student Social Media & Mental Health Impact Analysis

A data science project exploring the relationship between social media usage, lifestyle habits, academic engagement, and mental health outcomes among students.

---

## 📌 Project Overview

This project analyzes student survey data to uncover patterns and correlations between daily digital behavior (screen time, platform preferences, device unlocks) and personal well-being metrics (stress levels, sleep duration, physical activity, and overall mental health scores).

---

## 📊 Dataset Overview

The dataset contains structured demographic, behavioral, and psychological metrics across students from various academic levels:

| Feature | Description | Type |
| :--- | :--- | :--- |
| **Age** | Student age in years | Numerical |
| **Gender** | Self-reported gender | Categorical |
| **Country** | Country of residence | Categorical |
| **Academic_Level** | Education level (High School, Undergraduate, Graduate) | Categorical |
| **Most_Used_Platform** | Primary platform (e.g., Facebook, Instagram, LinkedIn, Snapchat) | Categorical |
| **Purpose_Of_Use** | Primary usage intent (e.g., Entertainment, Networking, Education) | Categorical |
| **Avg_Daily_Usage_Hours** | Daily time spent on social media (hours) | Numerical |
| **Daily_Unlocks** | Total daily device unlocks | Numerical |
| **Study_Hours** | Daily study duration (hours) | Numerical |
| **Physical_Activity_Hours** | Daily physical activity duration (hours) | Numerical |
| **Sleep_Hours_Per_Night** | Average nightly sleep (hours) | Numerical |
| **Stress_Level** | Perceived stress category (Low, Medium, Very High) | Categorical |
| **Mental_Health_Score** | Target rating scale for mental health | Numerical |

---

* **Data Visualization:** `matplotlib`, `seaborn`
